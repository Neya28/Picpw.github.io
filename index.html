ผลงานที่น่าสนใจ

โปรเจกต์ควบคุมไฟผ่านโทรศัพท์

ผลงานการสร้างระบบที่สามารถสั่งเปิดและปิดไฟ ผ่านโทรศัพท์มือถือ เพื่อเพิ่มความสะดวกในการใช้งาน

โครงงานสิ่งประดิษฐ์

การออกแบบและสร้างสิ่งประดิษฐ์จากแนวคิดของตนเอง โดยเน้นการนำความรู้ที่เรียนมาประยุกต์ใช้จริง

เว็บไซต์ Portfolio

การฝึกสร้างเว็บไซต์ด้วยภาษา HTML และออกแบบโครงสร้างหน้าเว็บให้อ่านง่าย

ทักษะของฉัน

  • HTML และ CSS
  • การเขียนโปรแกรมเบื้องต้น
  • การออกแบบเว็บไซต์
  • การใช้เทคโนโลยีและแอปพลิเคชัน
